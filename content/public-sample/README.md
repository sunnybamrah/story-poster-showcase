# The Next Game: public example

Pip and Dad are a fictional family. The kit contains one poster, two story pages, a practice page, and cards with a grown-up guide. The reminder is Name it to tame it.

The October25 visual revision keeps the same story and two-voice recording. It softens unrelated background detail in the poster and all four comic panels, keeps Dad’s purple sweater consistent, and removes a stray quote mark. All three practice choices now practise naming feelings. The grown-up page includes the checked study finding, its limits and clickable sources. Matching colour and black-and-white downloads contain the same complete five-page kit.

Only fictional reading data and nine hash-checked picture/download files are served. No real family photos, private stories, accounts, credentials or model logs are included. Earlier artwork and source files are preserved in the existing private review folders and version history.
